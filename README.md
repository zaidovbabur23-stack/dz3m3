# Notes AutoRoute (Flutter)

Готовый пример передачи `title` и `description` из `AddNoteScreen` в `ListNoteScreen` через `NoteModel` и AutoRoute.

## Запуск в VS Code
1. Открой эту папку в VS Code.
2. В терминале выполни `flutter pub get`.
3. Выполни `dart run build_runner build --delete-conflicting-outputs`.
4. Запусти `flutter run`.

> Если у тебя уже есть Flutter-проект, перенеси папки `lib` и зависимости из `pubspec.yaml` в свой проект, затем выполни команды генерации.
